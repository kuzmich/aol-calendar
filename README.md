# Календарь курсов и мероприятий ИЖ в Иркутске
Включает курсы, поддерживающие занятия, мероприятия в офисе, другие мероприятия типа «Дня
Йоги» и пр.

Сайт: https://calendar.maxc4m.serv00.net/ (старый адрес https://kuzmich.github.io/aol-calendar/
перенаправляет туда).

## Как устроено
Django + Postgres. События, типы курсов, места, учителя и статусы хранятся в базе и
редактируются в Django-админке (`/admin/`). Календарь на год (`/2026.html`) строится на лету:
события разбиваются на полоски по неделям и раскладываются по уровням, если в один день
их несколько (`events/grid.py`). Для визуализации используется CSS Grid: полоска события
позиционируется с помощью `grid-row` и `grid-column`.

Курсы планируются в календаре, а страница курса на artofliving.ru заводится в админке сайта,
когда она нужна. Страница «Синхронизация с админкой» в Django-админке загружает курсы за
месяц из админки сайта и сливает их с событиями календаря: связанные по `admin_id`
обновляются, для остальных ищутся события с тем же типом, датами и местом.

## Запуск
```
docker compose up -d                                   # Postgres на 127.0.0.1:5433
uv run --env-file .env manage.py migrate
uv run --env-file .env manage.py runserver 8001
uv run --env-file .env manage.py test events
```
Переменные окружения — в `.env` (образец в `.env.example`). Пакет `aa` для работы с админкой
artofliving.ru ставится из соседнего репозитория `../automation`.

## Деплой
`uv run fab deploy` собирает wheel-ы календаря и `aa`, ставит их на serv00, применяет
миграции и перезапускает сайт. Настройки сервера — в `settings_serv00.py` рядом с
`passenger_wsgi.py` (шаблоны в `deploy/`).
